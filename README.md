# Hua 🐱

一只治愈系的小猫 —— 送给林林的虚拟宠物 App。

## 下载

打开 [Releases 页面](https://github.com/zhihehua/Hua-LinLin/releases/latest)，
下载最新版的 `Hua_vX.X.apk` 即可。

## 安装

1. 把 APK 传到手机（或直接用手机浏览器打开上面的链接下载）
2. 点击安装；如果系统提示"未知来源应用"，选择"允许"即可
3. 打开 Hua，摸摸你的小猫吧～

## 玩法

| 手势 | 反应 |
| --- | --- |
| 单击头部 | 开心呼噜 |
| 单击身体 | 好奇回应 |
| 长按 | 趴下摆尾，撒娇循环 |
| 左右滑动 | 追着你的手看 |
| 双击 | 被吓一跳 |

> 摸猫会增加 Energy，双击会消耗～
